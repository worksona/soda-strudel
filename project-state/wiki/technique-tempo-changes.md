# Tempo changes and time feel

Part of [[repertoire-techniques]] · [[repertoire]].

setcpm/setcps set the speed; patterning the speed (a cps or cpm pattern) gives tempo changes within a piece, and uneven subdivisions or swing give the push and pull of pieces like Pyramid Song.

**Strudel docs:** https://strudel.cc/understand/cycles/
