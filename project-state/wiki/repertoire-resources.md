# Learning resources and tools

Part of [[repertoire]]. Levels: first steps · intermediate · performer. Reuse rules: [[repertoire-reuse-and-citation]].

## Learn – first steps

- **[Learning Music Production with Strudel: Free Course for Total Beginners](https://github.com/terryds/learning-music-production-with-strudel)** (`REP-R-009`, course) – A free, chaptered course on music production in the browser with Strudel, by terryds (who also keeps awesome-strudel). No license stated. * · repo last pushed 2025-11-15 · license: none stated · link 200*
- **[Live Coding For Music With Strudel.cc (Beginners)](https://www.youtube.com/watch?v=tKeJhjvTabc)** (`REP-R-010`, video) – YouTube beginner tutorial by Groovin in G: first patterns, drums and melody in strudel.cc. *Groovin in G · undated · license: YouTube standard license · link 200*
- **[Official Strudel Guide](https://strudel.cc/workshop/getting-started/)** (`REP-R-011`, docs) – The official getting-started workshop on strudel.cc – the canonical first lesson. Strudel docs: AGPL-3.0 project; check the site for content terms. * · undated · license: not stated · link 200*
- **[Creative Code Art - WORKSHOP // Coding Music With Strudel // Dan Gorelick and Viola He](https://www.youtube.com/watch?v=oqyAJ4WeKoU&ab_channel=CreativeCodeArt)** (`REP-R-012`, video) – Recorded workshop by Dan Gorelick and Viola He (Creative Code Art) – coding music with Strudel from the ground up. *Creative Code Art · undated · license: YouTube standard license · link 200*
- **[Intro To Algorave (Strudel Workshop)](https://glfmn.io/presentations/algorave/)** (`REP-R-013`, talk) – glfmn's "Intro to Algorave" Strudel workshop – slides/notes introducing algorave culture and live coding. * · undated · license: not stated · link 200*
- **[Learn how to make music through live coding // Lucy Cheesman](https://www.youtube.com/watch?v=QRJ0xrjLj6A)** (`REP-R-014`, video) – Lucy Cheesman (Heavy Lifting) on making music by live coding, recorded by Site Gallery. *Site Gallery · undated · license: YouTube standard license · link 200*
- **[Beats, Bytes, and Basslines: An Introduction to Live Coding Music with Strudel CC](https://mirakl.tech/beats-bytes-and-basslines-an-introduction-to-live-coding-with-strudel-cc-4d378e86d5b7)** (`REP-R-015`, article) – Mirakl Tech blog article introducing live-coding music with strudel.cc. The site refuses automated requests (403) – open it by hand to confirm. * · undated · license: not stated · link 403*

## Tools, converters and song repositories

- **[Strudel Songs Collection](https://github.com/eefano/strudel-songs-collection)** (`REP-R-001`, songs, all) – A large collection of Strudel songs and covers by eefano (the source for 9 tracks above). Script license: none stated – link and ask before adapting. *repo last pushed 2026-10-03 · none stated · ⭐488*
- **[Strudel Neovim Controller](https://github.com/gruvw/strudel.nvim)** (`REP-R-002`, editor integration, performer) – strudel.nvim – drive strudel.cc from Neovim: write patterns in your editor, play them in the browser. AGPL-3.0. *repo last pushed 2026-04-10 · AGPL-3.0 · ⭐493*
- **[MIDI to Strudel](https://github.com/Emanuel-de-Jong/MIDI-To-Strudel)** (`REP-R-003`, converter, intermediate) – Converts MIDI files into Strudel note notation (Python script or an HTML page). GPL-3.0. *repo last pushed 2026-05-07 · GPL-3.0 · ⭐81*
- **[midi-strudel](https://github.com/beejsbj/midi-strudel)** (`REP-R-004`, converter, intermediate) – Browser MIDI-to-Strudel converter: finds key, tempo, time signature and drum tracks, writes each track as absolute notes or scale degrees. No license stated. *repo last pushed 2026-10-26 · none stated · ⭐5*
- **[Melograph](https://github.com/beejsbj/melograph)** (`REP-R-005`, converter, first steps) – Hum or upload a melody, inspect its pitch contour and notes, edit, then open the generated Strudel code. GPL-3.0. *repo last pushed 2026-10-26 · GPL-3.0*
- **[PLAYER](https://github.com/abrambailey/player)** (`REP-R-006`, song builder, intermediate) – A local-first Strudel song builder: live code editor, step sequencer, piano roll, sound browser, timeline/arrangement, effect knobs, .strudel import/export. AGPL-3.0. *repo last pushed 2026-06-12 · AGPL-3.0 · ⭐15*
- **[maria-live-codes](https://github.com/Mariaareadne1/maria-live-codes)** (`REP-R-007`, songs, all) – MariaAreadne's cover songs for Strudel (Megalovania, Feel Good Inc, Vardis Quo and more) – copy into strudel.cc and play. No license stated. *repo last pushed 2026-07-30 · none stated · ⭐5*
- **[Toaster](https://github.com/StopBanning/toaster)** (`REP-R-008`, transcription, intermediate) – Listens to a song and writes it out as Strudel code as it plays – kick, hats, bass line, chords – then opens it in strudel.cc. MIT. *repo last pushed 2026-11-01 · MIT · ⭐101*
- **[strudel samples](https://strudel-samples.alternet.site)** (`REP-R-017`, sample browser, all) – strudel-samples.alternet.site – search and preview samples from known Strudel sample packs and add your own. *undated · not stated*
