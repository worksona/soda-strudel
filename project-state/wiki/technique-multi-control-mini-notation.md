# Several controls in one pattern

Part of [[repertoire-techniques]] · [[repertoire]].

Mini-notation can carry more than notes: a pattern like "s:n:gain" sets several controls at once from one string, so a whole voice (sound, note, gain, envelope) can be written on one line.

**Strudel docs:** https://strudel.cc/learn/mini-notation/
